# Arithmetic Progression Service
Этот микросервис предназначен для выполнения вычислений арифметической прогрессии в фоновом режиме. Он позволяет пользователям отправлять задачи на вычисление через HTTP API, отслеживать их статус, получать результаты.
# Основные возможности
- Задачи ставятся в очередь и обрабатываются пулом воркеров в фоновом режиме, не блокируя HTTP-запросы.
- Отслеживание статуса задачи.
- Простой HTTP-интерфейс для постановки задач, получения списка и статуса.
- Xранение состояния задач и результатов в памяти.
- Обработка задач в строгом порядке поступления.
# Технологии
- go/chi - лёгкий, идиоматичный и компонентный маршрутизатор для создания HTTP-сервисов на Go.
- shopspring/decimal - для сохранения точности вычислений.
- testify - для тестирования и моков.
# Запуск сервиса
- `go run main.go -workers 1`
- `-workers` - флаг для запуска опредленного числа обработчиков.
# HTTP API
## Постановка задачи 
### Запрос
`POST /task/set`
```JSON
{
  "elements_count": 100,      
  "start_number": 1.5,       
  "delta": 0.5,              
  "interval": 0.01
  "ttl": 1000           
}
```
- elements_count - количество элементов прогресии.
- start_number - первый элемент прогресии.
- delta - дельта.
- interval - интервал между итерациями.
- ttl - время хранения.
### Ответ
  `status: 201 created`
```JSON
{
  "status": "ok",
  "error": ""
}
```
